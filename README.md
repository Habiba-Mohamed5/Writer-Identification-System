# ✍️ Writer Identification System

A deep learning project to identify writers based on handwriting analysis using a Convolutional Neural Network (CNN) built with PyTorch Lightning, featuring an interactive GUI.

## 🚀 Features
- **Framework:** PyTorch Lightning for clean, scalable deep learning code.
- **Model:** Custom CNN architecture optimized for feature extraction from handwriting samples.
- **UI:** User-friendly GUI for real-time prediction/inference.
